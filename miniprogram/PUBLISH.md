# 发布存档（WESR-STOCK 小程序）

这份是**定稿 + 发布清单**：名称/简称/介绍/头像是已经选定并核对过微信规则的版本，
下面是提交前的四道门槛、提交流程和审核备注模板。改名前先看第六节，别把改名机会用掉。

## 一、定稿

| 项 | 定稿 | 核算 |
| --- | --- | --- |
| 小程序名称 | **WESR桌面屏助手** | `WESR` 4 + `桌面屏助手` 5 汉字×2 = **14 字符**（规则 4–30）✓ |
| 小程序简称 | **WESR** | **4 字符**（规则 4–10，**正好在下限**）✓，且是名称的前 4 个字符（规则要求从名称里按顺序截取）✓ |
| 功能介绍 | **给自研桌面屏做蓝牙配网与股票池设置的工具** | **20 字**（微信简介上限比这宽得多）✓ |
| 小程序头像 | **`design/avatar/avatar-d.png`**（折线 W + 圆角边框） | PNG、144×144、2.5 KB（要求 png/bmp/jpeg/jpg/gif、≤2M、建议 144×144）✓ |

- 名称里**刻意不含「股票 / 行情 / 证券」**：这类字样容易要求金融类目或资质，而个人主体
  一般拿不到金融类目。小程序本身也确实不展示行情（只配 8 个代码 + 名称，行情在板子上）。
- 简称取满下限的 4 字符，是因为 `WESR` 本身就是品牌、且必须是名称的连续片段。若控制台
  不接受恰好 4 字符（罕见），退路是名称里连续的 `WESR桌面屏`（4+3×2 = **10 字符**，仍在上限内）。
- 名称全平台唯一：在「设置 → 基本信息 → 小程序名称 → 修改」里输入即可看是否可用。
  **发布前只有 2 次改名机会，发布后 2 次/年**，所以定稿后别再随手改。

## 二、发布前的四道门槛

**1. 小程序备案（ICP）—— 没备案发不出去**

公众平台 → 设置 → 基本设置 → 小程序备案。个人主体也能备，提交后由通管局审，耗时较长，
**先提交、再并行准备其它步骤**。

**2. 服务器域名（request 合法域名）—— 本项目第一个坑**

公众平台 → 开发 → 开发管理 → 开发设置 → 服务器域名，加：

```
https://web.ifzq.gtimg.cn
https://proxy.finance.qq.com
```

为什么不加会坏：`project.config.json` 里 `urlCheck: false` 关掉了域名校验，而**豁免只对
开发版/真机调试有效**，体验版和正式版一律走白名单。症状是"输入代码自动补名称"退化成页面
提示「域名不在白名单里」，功能不崩但等于没做。

**3. 用户隐私保护指引里声明「蓝牙」—— 本项目第二个坑**

公众平台 → 设置 → 服务内容声明 → 用户隐私保护指引。蓝牙是隐私接口，不声明的正式版直接报：

```
openBluetoothAdapter:fail api scope is not declared in the privacy agreement
```

三屏全靠蓝牙（扫描 / 连接 / 下发），必须声明。Android 扫 BLE 还要用到位置权限，
把「位置信息」一并声明，省得用户手机上没弹窗、扫不到设备。

**4. 类目 —— 别选金融/证券**

选工具类（如「工具 > 效率」，或账号可选的智能硬件相关类目）。金融/证券类个人主体基本没有
资质，证券投资咨询还需牌照。

## 三、提交与发布

1. **上传**：开发者工具右上角「上传」→ 版本号（如 `1.0.0`）+ 项目备注。
   上传用的是**本地** `project.config.json` 里的 AppID（真实 AppID），仓库里那份是
   `touristappid`，别覆盖回去。
2. **体验版自测**：公众平台 → 管理 → 版本管理 → 开发版本「设为体验版」→ 加体验成员 →
   手机上把三屏走一遍。**体验版会执行域名与隐私校验**，是最接近正式版的验证。
   建议同时把「详情 → 本地设置 → 不校验合法域名」的勾去掉再真机跑一次。
3. **提交审核**：填功能页面 + 审核备注。审核员**手上没有这块板子**，三屏主流程全依赖 BLE
   硬件，很容易被判「功能无法体验」而驳回。备注建议照这个写：

   > 本小程序是自研硬件（ESP32-S3 桌面行情屏）的配网与配置工具，需与设备蓝牙连接使用。
   > 演示视频：<链接>。无设备时的预期表现：设备页扫描 6 秒后提示「先长按 KEY 3 秒让板子
   > 进配网模式」；配网页提示先连设备；股票页名称可手动填写并下发。小程序不展示行情数据。

4. **发布**：审核通过 → 版本管理 → 审核版本 → 发布（可先「分阶段发布」）。线上版本可回退。

## 四、提交前本地自查

- `node miniprogram/tools/selftest.js` 全绿（协议、页面接线、间隔白名单、名称规整）；
- 关掉「不校验合法域名」后真机再跑一遍；
- 头像文件格式/尺寸/体积（见第一节表格）；
- 代码包远小于主包 2MB 上限，不用管。

## 五、头像怎么重出

`design/avatar/gen_avatar.py`（Pillow，几何都用 0~1 分数写，改一个数就能重出）：

```bash
python design/avatar/gen_avatar.py
```

四个候选（A 分时线+量柱 / B 三根阳线 / C 折线 W / D W+圆角边框）+ `preview.png`
（288 原样、144 圆形、72 圆形、36 圆形 —— 36px 是任务栏那一档）。**定稿是 D**。
注意微信多处按圆形展示头像，脚本里的内容都收在圆形裁切范围内；若要再调，
改完看一眼 `preview.png` 里 36px 那一列还认不认得出。

## 六、名称/简称规则速查（改名前先算）

- 名称：中文/数字/英文/空格/部分特殊符号，**4–30 个字符，一个中文字 = 2 个字符**；
  全平台唯一（同主体下可与公众号同名）。
- 简称：**必须从名称里按顺序截取**（连续片段），**4–10 个字符**，一个中文字 = 2 个字符；
  不唯一，会显示在客户端任务栏。
- 改名次数：发布前名称/简称各 2 次；发布后各 2 次/自然年。名称修改期间简称不能改。
